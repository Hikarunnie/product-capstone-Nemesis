## Purpose
 
This file records weekly contributions by every Team Nemesis member. It is intended to support transparent individual grade adjustments.
 
The log was reconstructed from:
 
- the GitHub commit history;
- `00-foundation/team-contract.md`;
- `milestones/week-04-milestone.md`;
- `docs/standup-log.md`;
- `milestones/cp2-3-submission.md`;
- repository deliverables and named assignees;
- final-deliverable work completed during the project.
 
A commit count is not treated as the only measure of contribution. Interviews, usability testing, coordination, review, presentation work, and technical verification are included when repository documentation attributes them to a specific member.
 
Where no separate individual commit or artefact was recorded for a particular week, the entry states this directly. This does not mean that the member made no contribution; it means that the work was not separately attributable from the available repository evidence.
 
## Evidence Labels
 
| Label | Meaning |
|---|---|
| **GitHub-verified** | A named commit or authored repository file directly supports the entry |
| **Repo-documented** | A milestone, standup, checkpoint, or assignment table attributes the work to the member |
| **Team-level record** | The work formed part of shared planning, review, or delivery, but no separate individual artefact was recorded |
| **Prepared for commit** | The work was completed for the final submission and should be verified after it is committed |
